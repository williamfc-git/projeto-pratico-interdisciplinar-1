PROJETO PRÁTICO INTERDISCIPLINAR I

O desafio é criar essa página utilizando HTML e CSS. 

Siga as instruções abaixo:

a)	Crie uma página HTML chamada "menu.html".

b)	Adicione um cabeçalho contendo o nome do restaurante, um logotipo fictício (você pode usar uma imagem de exemplo) e um menu de navegação com links para a página do menu e qualquer outra página que você deseje adicionar.

c)	No corpo da página, crie três seções distintas, uma para cada tipo de prato (entrada, prato principal e sobremesa). 

Cada seção deve incluir:
d)	Um título indicando o tipo de prato.

e)	Para cada tipo, inclua pelo menos dois pratos com os seguintes detalhes para cada prato:

•	Nome do prato.

•	Uma breve descrição.

•	O preço do prato.

f)	Utilize CSS para estilizar a página e os elementos, aplicando uma formatação visual atraente. Certifique-se de usar seletores CSS para estilizar elementos de forma consistente.

g)	Adicione imagens de pratos (você pode usar imagens de exemplo ou criar suas próprias) para tornar o menu mais atrativo.

h)	Implemente um rodapé com informações de contato fictícias para o restaurante.
